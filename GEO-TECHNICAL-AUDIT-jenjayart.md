## Critical Issues — Fix Immediately

### 1. llms.txt Missing (GEO Impact: HIGH)
- **URL:** https://jenjayart.com.au/llms.txt → 404
- **Impact:** All AI systems (ChatGPT, Claude, Perplexity, Gemini) have no machine-readable summary of who Jen Jay is, what she offers, or how to cite her. This is the single highest-ROI GEO fix available.
- **Fix:** Create `/llms.txt` at the root of the domain. See template below.

### 2. No H1 Tag on Homepage (GEO + SEO Impact: HIGH)
- **URL:** https://jenjayart.com.au/
- **Evidence:** Raw HTML scan found 0 H1 tags on the homepage. Only H2s detected: "ABOUT ME" and "JEN JAY"
- **Impact:** AI systems use H1 as the primary topic signal for a page. Without it, the page has no clear topical authority anchor. Google also uses H1 as a strong on-page ranking signal.
- **Fix:** Add a single H1 on the homepage — e.g., `<h1>Award-Winning Sunshine Coast Artist | Jen Jay Art</h1>`

### 3. Homepage Page Title 99 Characters (Too Long)
- **Current:** "Jen Jay Art l Award-winning Artist Sunshine Coast Jen Jay Art l Award-winning Sunshine Coast Artist" (99 chars)
- **Impact:** Google truncates titles at ~60 characters in SERPs. The brand name appears twice, signalling duplication. AI systems read the full title but the redundancy wastes keyword space.
- **Fix:** Shorten to ~55 chars: `"Jen Jay Art | Award-Winning Sunshine Coast Artist"`

### 4. All Security Headers Missing (Trust + Ranking Signal)
- **Evidence:** HTTP response headers contain only `Cache-Control`. No HSTS, no X-Content-Type-Options, no X-Frame-Options, no Referrer-Policy, no Content-Security-Policy.
- **Impact:** Modern browsers flag missing security headers. Google uses HTTPS and security signals as ranking factors. Missing HSTS means HTTPS is not enforced at the browser layer.
- **Fix:** Add to Apache `.htaccess` or server config (see recommendations section below).

### 5. TTFB 1.69 Seconds (Poor — Target < 800ms)
- **Evidence:** `curl` timing shows TTFB of 1.691s, total 1.758s
- **Impact:** LCP will likely be > 2.5s (Poor threshold). This directly affects Core Web Vitals and page ranking. A fast TTFB is also correlated with faster AI crawler indexation.
- **Root cause:** No CDN detected (no CF-Ray, no X-Cache headers), Apache server responding slowly, likely no server-side caching plugin active.
- **Fix:** Install WP Rocket or W3 Total Cache, or activate server-side page caching. Add Cloudflare as CDN proxy (free tier covers this site's scale).

## High Priority Issues — Fix This Week

### 6. Meta Descriptions Are Generic Boilerplate (GEO + CTR Impact)
All pages share the same template description with only the page name prepended:
`"[Page Name] Jen Jay Art offers original pieces, commissions, and engaging art classes..."`

This is Yoast's default fallback — it means no unique meta description has been written for any page.

| Page | Current Description Issue |
|---|---|
| Homepage | Uses same boilerplate as all other pages |
| About/Artist | Starts with just "About" then boilerplate |
| Workshops | Starts with "Art Workshops & Lessons" then boilerplate |
| Online Lessons | Starts with "Online Art Lessons" then boilerplate |
| Extension Course | Starts with "Extension Workshops" then boilerplate |
| Art Store | Starts with "Art Store" then boilerplate |
| Art Gallery | Starts with "GALLERY" (all caps) then boilerplate |
| Get in Touch | Starts with "Get in Touch" then boilerplate |

**Fix:** Write unique, specific meta descriptions for each page (see recommendations below).

### 7. OG Image Uses 150x150 Thumbnail
- **Evidence:** `<meta property="og:image" content=".../Peonies-150x150.jpg">`
- **Impact:** Facebook, LinkedIn, and messaging apps will show a tiny, pixelated thumbnail when the site is shared. Recommended minimum: 1200x630px. Twitter/X requires minimum 600x314px.
- **Fix:** In Yoast SEO settings, set the Social Image to a high-quality landscape artwork image at 1200x630px.

### 8. No Twitter Card Meta Tags
- **Evidence:** No `twitter:card`, `twitter:title`, or `twitter:image` tags found in raw HTML
- **Impact:** Twitter/X will not display a rich card when the site is shared. Reduced click-through from social platforms.
- **Fix:** Enable Twitter Card settings in Yoast SEO (Settings > Social > Twitter).

### 9. ecstore Sitemap Has No lastmod Dates
- **Evidence:** The 5 product URLs in `ecstore-sitemap.xml` use `changefreq` and `priority` but no `<lastmod>` dates
- **Impact:** Search engines use `lastmod` to prioritise crawling fresh content. Without it, product pages may be crawled less frequently.
- **Fix:** Configure Ecwid/Yoast to output `lastmod` for e-commerce URLs, or manually set via Yoast's sitemap settings.

### 10. No LocalBusiness, Person, or Service Schema
- **Evidence:** Yoast generates only `WebPage`, `WebSite`, `BreadcrumbList`, and `ImageObject` schema types
- **Impact:** This is the most significant GEO gap after llms.txt. AI systems rely on structured data to understand:
  - Who the person is (Person schema)
  - Where the business operates (LocalBusiness schema)
  - What services are offered (Service schema)
  - Product details (Product/Offer schema on store)
- **Fix:** Add custom schema markup (see schema recommendations below).

### 11. Viewport Blocks User Zoom (Mobile Accessibility Issue)
- **Evidence:** `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=0">`
- **Impact:** Disabling user zoom (`user-scalable=0`, `maximum-scale=1.0`) fails WCAG 2.1 Success Criterion 1.4.4. Google's mobile-first indexing flags this as an accessibility issue and it can reduce mobile usability scores.
- **Fix:** Remove `maximum-scale=1.0` and `user-scalable=0` from the viewport meta tag. Change to: `content="width=device-width, initial-scale=1.0"`

### 12. WebSite Schema Has Wrong Description
- **Evidence:** In Yoast's JSON-LD, the WebSite schema contains `"description":"KissMyArt Workshops"` — this appears to be a legacy/test value
- **Impact:** AI systems read this description as the site's primary description. "KissMyArt Workshops" does not represent the brand accurately.
- **Fix:** Update in Yoast SEO > Settings > Site Basics to set the correct site tagline.

## Security Headers Fix

Add the following to the WordPress site's `.htaccess` file (before the `# BEGIN WordPress` block):

```apache
# Security Headers
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "SAMEORIGIN"
Header always set Referrer-Policy "strict-origin-when-cross-origin"
Header always set Permissions-Policy "geolocation=(), microphone=(), camera=()"
```

Alternatively, if the site is proxied through Cloudflare, these can be set via Cloudflare's Transform Rules with zero server access required.
