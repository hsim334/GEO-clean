# GetCitedGEO — Static Image Ad Concepts
*10 concepts × multiple variations. Built on brand DNA (aurora/liquid glass) + stcs.md sales psychology.*

---

## Visual System Reference

Apply these consistently across all 10 concepts:

| Element | Spec |
|---|---|
| Background | `#020205` deep blue-black void |
| Aurora Layer | 3 overlapping radial gradients: Indigo `#6366f1`, Fuchsia `#d946ef`, Cyan `#06b6d4` — blurred, glowing |
| Cards/Panels | Liquid glass: `backdrop-filter: blur(32px)`, subtle white gradient sheen, light-catch on top+left border |
| Heading font | Outfit 800–900 weight, tight tracking (-1px to -2px) |
| Body font | Plus Jakarta Sans — clean, UI-native feel |
| Score colour | Red/orange for low scores, green for high — always on a liquid glass panel |
| Ad size | 1080×1080 (feed), 1080×1920 (story/reel cover), 1200×628 (link preview) |
| CTA style | Soft — "Get your free audit" never "BUY NOW" |

## Notes on Production

- Never use stock photography — screenshots, score visuals, data panels only
- The liquid glass cards should actually look like the website — use Figma/design tool to recreate the exact CSS effect as a static export
- All dark backgrounds should have aurora glow visible — not flat black
- Score numbers always in Outfit 900
- Body copy always Plus Jakarta Sans
- No gradients on text unless intentional (white or muted white only for data/copy)
- CTA on all ads: "Get your free audit" or "See your score" — never "Buy now" or "Sign up"
