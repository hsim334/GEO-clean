## Critical Issues (Fix Immediately)

### C1 — Legacy "KissMyArt Workshops" in WebSite Schema
**Pages affected:** All pages (sitewide via Yoast SEO)
**Issue:** The existing `WebSite` JSON-LD schema contains `"description": "KissMyArt Workshops"` — an old test value. Every AI crawler reading this site's structured data is told the business is called "KissMyArt Workshops," not "Jen Jay Art." This actively corrupts entity recognition.
**Fix:** In WordPress Admin > Yoast SEO > Search Appearance > General, update the site description to: *"Jen Jay Art — Award-winning artist and art teacher on the Sunshine Coast, Queensland. Acrylic painting, palette knife workshops, private lessons, and online courses."* Verify with Google's Rich Results Test.

### C2 — No Schema Entity Anchor (Person / VisualArtist / LocalBusiness)
**Pages affected:** Homepage, About page
**Issue:** AI systems cannot reliably identify "Jeanette Smith" (an extremely common name) as this specific artist without a structured entity anchor. The site exists to AI knowledge graphs only as floating text.
**Fix:** Implement `VisualArtist` + `LocalBusiness` JSON-LD on the homepage and `Person` schema on the About page. See Schema section for exact code.

### C3 — No llms.txt File
**Issue:** Returns 404. This is the fastest single action to improve AI crawler guidance — a 30-minute task that tells AI systems exactly who Jen Jay is, what she offers, and how to cite her correctly.
**Fix:** Create `/llms.txt` at the domain root. Template provided in Technical GEO section below.

## High Priority Issues (Fix Within 1 Week)

### H1 — No Meta Description on Homepage
The homepage has no meta description. Every other page has a meta description generated by Yoast, but they are all identical boilerplate (page name + same repeated sentence). AI systems use meta descriptions as summary signals.
**Fix:** Write a unique 150-character meta description for each page. See Technical GEO section for per-page recommendations.

### H2 — No Google Business Profile
No Google Business Profile (GBP) found for Jen Jay Art. This is the single highest-ROI action for local AI query visibility ("art classes near me," "art workshops Sunshine Coast"). AI systems including Google AI Overviews, ChatGPT with Browse, and Perplexity Local draw directly from GBP data.
**Fix:** Create a Google Business Profile at business.google.com. Categories: Art Studio + Art School. Add address, photos, hours, all services. Request reviews from past students.

### H3 — Zero FAQ Content Across All 8 Pages
No FAQ sections exist anywhere on the site. FAQ content is among the highest-citability formats for AI systems — structured question + answer pairs are extracted and reproduced almost verbatim.
**Fix:** Add a minimum 8-question FAQ to the Workshops page and 8 questions to the Extension Course page. Implement FAQPage schema on both. Priority questions listed in AI Citability section.

### H4 — No Trust Layer (ABN, Policies, Terms)
No ABN displayed, no Privacy Policy, no Workshop Cancellation Policy, no Course Refund Policy, no Store Terms & Conditions. The site takes payments at $55–$199 per transaction with zero stated terms. This suppresses AI trust scoring and may create ACL exposure.
**Fix:** Display ABN in footer. Create four policy pages (Privacy, Workshop Cancellation, Course Refund, Store T&Cs). Each can be drafted from ACCC-provided templates in one afternoon.

### H5 — Testimonials Are Unverifiable
Only two testimonials used sitewide ("Paul Brisbane," "Lisa QLD"), both first-name-only with no date, no photo, no platform link. AI systems treat unverifiable testimonials as negligible trust signals.
**Fix:** Re-attribute with format: "Paul M., Brisbane, Palette Knife Workshop, March 2025." Add 8 Google reviews as the primary verification layer. List on ClassBento and Superprof for indexed third-party reviews.

### H6 — No Homepage H1 Tag
Raw HTML analysis confirmed zero H1 tags on the homepage despite using WordPress/Divi. This is a structural content signal failure.
**Fix:** In the Divi page builder, ensure the "JEN JAY" heading is set to H1 type. Do not have multiple H1s.

### L3 — Core Web Vitals Failing (TTFB 1.69s)
No CDN, no compression headers, no page caching detected. Slow page load degrades user experience and is a minor AI accessibility signal.
**Fix:** Install a WordPress caching plugin (WP Rocket or W3 Total Cache) and enable Cloudflare (free tier) as a CDN.

### L4 — All 5 Security Headers Missing
No HSTS, CSP, X-Frame-Options, X-Content-Type-Options, or Referrer-Policy. Not a GEO issue but an infrastructure quality signal.
**Fix:** Add security headers via .htaccess or a security plugin (Wordfence, iThemes Security).

### L5 — Viewport Blocks User Zoom
The viewport meta tag includes `user-scalable=0`, which is a WCAG accessibility failure and a Google mobile usability flag.
**Fix:** Change to `<meta name="viewport" content="width=device-width, initial-scale=1">`.

### L6 — Commission Service Has No Dedicated Page
Custom commissions are mentioned on three pages but never explained. This is likely the highest-revenue service with zero citable content.
**Fix:** Create a `/commissions/` page: 600 words covering the process, price range, timeframes, minimum canvas sizes, and a FAQ section.

### AI Citability (22/100)

**Summary:** The site has genuine credentialing and real data — awards, prices, dates, named venues — but almost no content is structured so an AI can extract and quote it as a standalone answer to a specific question. The artist statement is poetic; the workshop descriptions are outcome-focused rather than technique-focused; the gallery has titles but no descriptions.

**Citable passages that currently work:**

1. **Price list (Workshops page)** — "Students 8's to Teens: 1.5 hours, $55. Palette Knife Workshop: $160. Private Lessons: 1.5 hours, $65. Paint to You: $75/person, minimum 8 participants." Self-contained prices. An AI can extract this to answer "how much do art lessons cost on the Sunshine Coast."

2. **Artist in Residence credential (About page)** — "Artist in Residence, The Sebel Hastings Street, Noosa (2017–2020)." Named entity, specific dates, clear role.

3. **Magazine feature (About page)** — "In Noosa Magazine (Spring 2021, front cover and artist editorial)." Named publication, specific date, specific placement.

4. **Group class spec (Online page)** — "Every Tuesday, 10 AM–1 PM, Peregian Springs. Group size: 4–6 students. First class: $55, subsequent: $45." Specific, actionable, answerable.

5. **Lisa testimonial** — "After your easy to follow instructions I couldn't believe how mesmerised I became when painting the tree, it was like being in a meditation trance." First-person, vivid, specific.

**Top 10 citability gaps (questions the site cannot answer):**

1. "What is palette knife painting?" — One vague sentence. No definition, no technique explanation.
2. "What is colour theory for beginners?" — Five identical lesson descriptions. No definition of colour theory itself.
3. "How do I commission a painting on the Sunshine Coast?" — Service mentioned but no process, no pricing, no page.
4. "What qualifications does Jen Jay have as an art teacher?" — "Qualified Art and Design Teacher" stated but no institution, no qualification name, no year.
5. "How long does it take to learn to paint from scratch?" — Not addressed anywhere.
6. "Acrylic vs oil painting — which is better for beginners?" — Course mentions both, never explains the difference.
7. "Are there art workshops for adults on the Sunshine Coast?" — Adults must infer they're welcome; never stated directly.
8. "What awards has Jen Jay won?" — Long chronological list with no summary sentence.
9. "What kind of art does Jen Jay make?" — Artist statement is poetic, not descriptive. No style/medium explanation.
10. "What is a Sip and Paint event and how much does it cost?" — Mentioned three times, never described or priced.

**Rewrite Priority 1 — Homepage identity block:**

*Current:* "My artwork is the by-product of my observation, creative influences, life experiences and my passion to keep discovering."

*Recommended:* "Jen Jay (Jeanette Smith) is an award-winning Australian artist and qualified art teacher based in Peregian Springs on Queensland's Sunshine Coast. She has won multiple awards at the Pacific Palms NSW Art Festival (2008, 2010, 2012), held a solo exhibition at Maroochydore Library in 2022, and served as Artist in Residence at The Sebel Hastings Street Noosa from 2017 to 2020. She offers private art lessons, group workshops, palette knife painting classes, and a $199 online colour theory course for beginners."

**Rewrite Priority 2 — Define palette knife painting:**

*Current:* "Pallet knife painting is a fun hands-on way of getting you into painting without being too technical."

*Recommended:* "Palette knife painting is a technique in which paint is applied to canvas using a flexible metal blade — called a palette knife — instead of a brush. The result is thick, textured impasto marks that create a semi-abstract, sculptural quality impossible to achieve with brushwork alone. Jen Jay's Palette Knife Workshop ($160) runs at her Peregian Springs studio on the Sunshine Coast and suits all skill levels, including complete beginners. The session covers knife selection, paint loading, mark-making techniques, and composition on a canvas. All materials are included."
